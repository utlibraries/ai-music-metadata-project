Individual Steps
Run any step independently
Step 0.5
Validate image filenames
Checks all image files follow the barcode naming convention before any API calls are made.
Step 1 -- AI Metadata Extraction
Extract metadata from CD cover images
Sends CD cover images to OpenAI vision model. Extracts title, artist, publisher, UPC, tracks, year. Uses batch processing automatically for 50% cost saving when batch has 10+ items.
Step 1.5 -- Metadata Normalization
Clean and normalize extracted metadata
Standardizes extracted metadata -- fixes date formats, normalizes publisher names, extracts UPC codes so OCLC queries are as accurate as possible.
Step 2 -- OCLC WorldCat Search
Search OCLC for matching records
Builds multiple search queries per CD (UPC first, then title+artist combinations) and searches OCLC WorldCat. Returns up to 5 CD-format matches. Checks IXA holdings for each match.
Step 3 -- AI Match Analysis
AI confidence scoring of OCLC matches
GPT-4.1 compares extracted metadata against OCLC results. Selects best match, assigns 0-100% confidence score. Records scoring 70%+ go to high confidence batch upload. Uses batch mode for 50% cost savings.
Step 4 -- Verification and Alma Holdings Check
Verify tracks, years, and check Alma for duplicates
Cross-checks track listings and years. Queries live Alma to confirm whether each OCLC number is already held by UT Libraries. Deduplication layer 2.
Step 5 -- Generate Output Files
Sort records and create all deliverable files
Sorts all records into: High Confidence (Alma batch upload), Held by UT Libraries, Low Confidence (cataloger review), Duplicates. Creates sorting spreadsheet, batch upload file, tracking spreadsheet, MARC file.
Step 6 -- HTML Review Interface (Optional)
Generate visual cataloger review interface
Creates a visual HTML review interface showing each CD image alongside the AI-suggested OCLC match and confidence score. Recommended for batches of 500 items or fewer.

Original Cataloging
Three-step automated workflow for CDs with no OCLC match
Records scoring 70%+ confidence are processed automatically. Records below 70% require HTML review before OCLC submission.
Step 3b -- AI MARC Generation
Generate enriched MARC records from CD images
Reads Step 1 metadata for all no-OCLC-match records. GPT-4.1 generates complete MARC records: 007, 1xx, 245, 264, 300, 336-338, 500, 505, 518, 588, 650, 700. Applies sentence case. Records 70%+ confidence go to batch-ready file automatically.
Step 3c -- Create OCLC Records
Submit approved records to OCLC WorldCat
Accepts batch-ready .txt file (70%+ confidence, no review needed) or cataloger decisions CSV from HTML review. Searches OCLC before creating any record (deduplication). Creates new OCLC bibliographic records. Sets IXA holdings immediately.
Step 3d -- Import to Alma
Import approved original records to production Alma
Reads workflow JSON for records with assigned OCLC numbers. Checks Alma before creating any record (deduplication layer 3). Creates bib + holdings (sf/sffi) + item record. Internal note: KUT Collection AI Assisted Cataloging -- Original Record.
Warning: This writes to PRODUCTION Alma. Dedup check runs before every record.

Visual cataloger review of low confidence matches

Process exported decisions CSV
After reviewing and exporting decisions from the HTML interface, Step 7 updates the sorting spreadsheet, batch upload file, tracking spreadsheet, MARC file, and decisions-history audit trail.
